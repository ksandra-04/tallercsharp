# Taller de Programación Inicial en C#

Este es mi proyecto con la solución a los 15 ejercicios básicos del taller, hecho en C# con .NET.

## ¿Cómo lo ejecuto?

1. Abro la carpeta en Visual Studio (o cualquier editor con soporte para C#).
2. Ejecuto el proyecto con el botón de Iniciar, o con `dotnet run` desde la terminal, dentro de la carpeta del proyecto.
3. Me aparece un menú en la consola donde elijo el número del ejercicio que quiero probar.

## Ejercicios que resolví

1. Positive Power
2. Double or Triple
3. Root or Square
4. Circle Perimeter
5. Midweek Day
6. Tax Calculator
7. Remainder Finder
8. Sum of Evens
9. Fraction Difference
10. String Length
11. Average of Four
12. Smallest of Five
13. Vowel Counter
14. Factorial Finder
15. InRange Validator

## Notas

Resolví cada ejercicio en un método aparte dentro de `Program.cs`, y dejé comentarios explicando en palabras simples qué hace cada parte del código.
